## Cách tải và chuẩn hoá ảnh

```bash
pip install requests pillow

# Bước 1 — tải ảnh ứng viên từ các bài báo nguồn (vào _candidates/, chưa commit)
python fetch_images.py

# Bước 2 — duyệt _candidates/, chọn ảnh đúng cho từng mục,
#          copy vào folder này với tên vn-01.jpg … vn-12.jpg

# Bước 3 — nén về ≤800px, JPEG q82, xoá EXIF (đúng chuẩn examples/durex-reference/)
python fetch_images.py --normalize

# Bước 4 — xoá thư mục tạm rồi commit
rm -rf _candidates
```

`_candidates/` đã nằm trong `.gitignore` của script (không lo commit nhầm ảnh chưa duyệt).

## Bản quyền

Các hình trong folder này thuộc bản quyền **Durex / Reckitt Benckiser** và các agency thực hiện (Isobar Vietnam, MSL Group…). Chỉ lưu ở độ phân giải thấp (≤800px) phục vụ **học tập và bình luận** về phương pháp sáng tạo quảng cáo — không dùng cho bất kỳ mục đích thương mại nào. Chủ sở hữu quyền thấy không ổn xin mở issue, nội dung sẽ được gỡ ngay.
